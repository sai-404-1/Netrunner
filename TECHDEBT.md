# Технический долг

## Модульная система

### availability_check, inventory_collect
Реализуют `run_for_host` с нестандартной логикой: несколько SSH-команд на хост,
парсинг вывода, запись в таблицу inventory. Несовместимы с `CommandModule`.
Трогать только при полном переосмыслении модуля.

### mass_ssh
Имеет собственный `run_for_host`. Технически может быть переписан через
`CommandModule` с `command = "$command"`, но текущий вариант работает корректно.
Схема добавлена — фронтенд рендерит форму динамически.

### apt_package_manager
Сложный модуль: собственный парсинг вывода apt, обнаружение изменённых пакетов,
поддержка sudo_password через stdin. `CommandModule` здесь не применим.
Схема добавлена — фронтенд рендерит форму динамически.

---

## Типы полей схемы

Сейчас поддерживаются: `text`, `textarea`, `password`, `select`.

Возможные расширения (не реализованы):
- `number` — числовой ввод с min/max
- `checkbox` — булевый флаг
- `multiselect` — множественный выбор
- `file` — загрузка файла на сервер перед запуском
