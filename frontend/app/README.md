# frontend/app

Маршруты Next.js (App Router). Каждая папка `*/page.tsx` — отдельная страница панели;
большинство — клиентские компоненты (`"use client"`), которые ходят на бэкенд через
`lib/api-client.ts` с куки-аутентификацией.

## Каркас
- `layout.tsx` — корневой layout (провайдеры, шрифты; инлайн-скрипт темы до отрисовки,
  `<html suppressHydrationWarning>`).
- `page.tsx` — главная страница **«Обзор»** (дашборд: сводка по хостам/задачам/отчётам).

## Страницы
- `hosts/page.tsx` — **Хосты**: реестр узлов, добавление/редактирование, проверка
  доступности, перепривязка SSH-ключа, режим «Доска». «Зарегистрированные хосты» и
  «Группы» объединены в один блок с **вкладками** (поиск/фильтр — строкой).
- `modules/page.tsx` — **Модули**: встроенные и пользовательские модули в одном блоке с
  **вкладками**; загрузка/включение, схемы.
- `run/page.tsx` — **Запуск задачи**: выбор модуля и цели, аргументы, **живой прогресс по
  хостам** (в очереди / выполняется / готово / ошибка); для модуля `file_distribute` —
  менеджер файлов (`FileManager`).
- `history/page.tsx` — **История**: **вкладки «История» / «Отчёты»** (отчёты — через
  `components/ReportsView.tsx`).
- `scheduled/page.tsx` — **Планировщик**: запланированные/повторяющиеся задачи.
- `inventory/page.tsx` — **Инвентаризация**: снимки оборудования/ОС по хостам.
- `reports/page.tsx` — рендерит `ReportsView` (маршрут оставлен; из сайдбара убран,
  контент — во вкладке «История»).
- `scenarios/page.tsx` — **Сценарии**: цепочки модулей; запуск **в фоне** с живым
  опросом — панель «Выполнение» подсвечивает активный шаг/модуль и статус каждого шага.
- `keys/page.tsx` — **Ключи**: SSH-ключи (загрузка, генерация, ключ по умолчанию).
- `account/page.tsx` — **Профиль**: смена своего имени/пароля, переключатель темы,
  привязка Telegram и список доверенных устройств (2FA: отозвать / доверять бессрочно);
  внизу — «Выйти из аккаунта».
- `admin/page.tsx` — **Администрирование**: слева — пользователи (добавление + список),
  справа — «Обновление» (`UpdatePanel`), ниже — бэкап/восстановление БД.
- `update/page.tsx` — рендерит `UpdatePanel` (маршрут оставлен; из сайдбара убран,
  контент — в админке).
- `login/page.tsx` — форма входа; двухшаговая при 2FA (пароль → одноразовый код из
  Telegram + чекбокс «доверять устройству 1 час»).

## Серверные роуты
- `api/login/route.ts` — логин: проксирует на бэкенд, ставит httpOnly-куки `netrunner_token`
  (только после полной аутентификации) и долгоживущую `netrunner_device` (id устройства
  для 2FA). При `mfa_required` токен не выдаётся — возвращает челлендж.
- `api/login/verify/route.ts` — второй шаг 2FA: шлёт код + `device_id` на бэкенд, при успехе
  ставит `netrunner_token`.
- `api/logout/route.ts` — логаут: сбрасывает куки.
